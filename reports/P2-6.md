# P2-6: "Connect an agent" box

- Branch: `night/P2-6` · Instance: A (phase-0 session) · Date: 2026-11-13
- Status: done

## Done

- Settings › Agents › connect box (shown after creating an agent or a new
  token): one tab per client with ready-to-copy instructions:
  - **Claude Code**: `claude mcp add --transport http atrium <url> --header "Authorization: Bearer <token>"`
    (shell-quoted), plus the `.mcp.json` alternative;
  - **Claude Desktop**: `claude_desktop_config.json` entry through
    `npx -y mcp-remote <url> --header Authorization:${ATRIUM_AUTH}` with the
    token only in `env` (local config entries cannot send headers themselves);
    note that claude.ai custom connectors need OAuth (P2-7);
  - **Cursor**: `mcp.json` with `url` + `headers`;
  - **Codex**: `config.toml` with `bearer_token_env_var`, token in an
    `export` line (kept out of the config file);
  - **Script (REST)**: a small `atrium.sh <tool> [json]` wrapper around curl,
    first call `agent_whoami`, a word on `events_since`.
- The guides are a pure function, `connectGuides()` in
  `core/web/shell/settings/agentsModel.ts`, built in the browser from the URLs
  and token the server already returns. **No server change** (server/ is being
  worked on by the other night instance).

## Tested

# V4-21: the version next to the logo, and a page saying what each version brought

- Branch: `night/V4-21` · Instance: oxygen-night · Date: 2026-11-23
- Status: done

## Done

A small pill next to the name in the header says which version this Wavium is
(`v4.1`), and opens **Settings > What's new**: one card per version, newest
first, the one being run marked "You are here".

- `core/web/shell/whatsnew.ts` — the content: version, date, a one-line
  headline and what changed, in plain words, for v1 through v4.1. `CURRENT` is
  the first entry, which is what the badge shows.
- `core/web/shell/settings/WhatsNew.tsx` — the page. It also names the
  Nextcloud release underneath, read from `status.php` like Settings > Overview
  does, and formats dates with the shell's `formatDate`.
- `core/web/shell/Shell.tsx` + `shell.css` — the badge. It stays visible on a
  phone (where the name is hidden): knowing which version you are on is the
  whole point of it.
- `CHANGELOG.md` — a `## v4.1` section; the changelog stays the long technical
  account, the page is the short one.

**One source of truth.** The badge and the page both read `RELEASES`, and
`whatsnew.test.ts` compares `RELEASES` to the `## vX` headings of
`CHANGELOG.md`: same versions, same order, and `CURRENT` is the newest. A
release tagged and written in the changelog can no longer ship with the badge
still naming the version before it -- checked by breaking it (renaming the
entry to `v4.9` fails two of the five tests).

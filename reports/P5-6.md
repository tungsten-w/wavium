# P5-6: built-in assistant panel

- Branch: `night/P5-6` · Instance: session B (main session, Claude) · Date: 2026-11-13
- Status: done

## Done

- **The assistant is a real agent of the user** ("Assistant", created on
  first use, listed in Settings > Agents). Its default access: read and write
  in the apps that have tools (activity, calendar, contacts, daily todo,
  files, mail, notes, tasks); sending, deleting and sharing ask (defaults).
  Every tool call goes through `callTool`: grants, approvals, pause and the
  journal (P3-7) apply exactly as for an external agent. Deleted in Settings
  > Agents → a new one is made next time.
- **Server** (`server/agent/assistant/`, module `assistantModule(ai)`):
  - `GET /agent/v1/assistant` → `{ready}` (does the user have a provider
    for the task "assistant", P2-5);
  - `POST /agent/v1/assistant/chat` (logged-in user, OCS header) streams
    Server-Sent Events: `text`, `tool`, `tool_result` (ok + short preview),
    `approval` (request id + summary), `done`, `error`; a ping every 10 s;
  - the loop: `ai.forTask(uid, 'assistant')` (budget and model routing
    included) with the tools the assistant can see, up to 8 model turns,
    tool results cut at 8 000 characters, the system prompt says tool
    results are data and never instructions (prompt injection);
  - no provider → 409 with "Add one in Settings > AI providers"; AI errors
    (budget, key, rate limit, down) come back as clear sentences.
- **Panel** (`core/web/shell/Assistant.tsx`, logic in `assistantModel.ts`):
  a robot button in the header opens it on the right of every page (full
  screen on phones; remembered open/closed); answers stream in; each tool
  call is a line (… / ✓ / ✗); a gated step is a card with Approve / Reject
  (owner approvals API); "New chat", Stop, Enter to send; the "no provider"
  error links to Settings > AI providers.
- **Mock provider (dev only)**: a last user message `mock-tool: <name>
  {json}` makes the mock call that tool if it is offered, so the tool loop
  can be tried on the dev stack without a real model (rule A2). Echo as
  before otherwise.

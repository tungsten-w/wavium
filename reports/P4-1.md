- Status: done for undo delete, contact autocomplete, conversation view,
  snooze, tags and HTML compose. The unified inbox already existed (Inbox =
  every account's inbox). Sieve filters are left (filing rules, P5-3, cover the
  common need without the mail server).

## Done

- **Undo delete**: deleting moves the mail to Trash, as before. The toast now
  says "Moved to Trash" with **Undo**. Undo syncs Trash, finds the mail again
  by its Message-ID (its database id changed in Trash) and moves it back.
  Route: `POST /agent/v1/mail/undo-delete` (`server/agent/mailundo/`).
- **Contact autocomplete** in To / Cc / Bcc (`AddressField.tsx`): from 2
  letters, Mail's own autocomplete (contacts + people you wrote to). Keyboard
  arrows, Enter or Tab to pick; it completes the last address of the field.
- **Conversation view**: under the open mail, the other messages of its
  thread (Mail's `/api/messages/<id>/thread`), oldest first; a click opens
  one.
- **Snooze**: ⋮ > Snooze… offers later today 18:00 (before 17:00), tomorrow
  08:00, next Monday 08:00, or a date. On first use the account gets a
  "Snoozed" folder. Mail's WakeJob brings the mail back.
- **Tags** (P4-1b): a coloured chip per tag in the list; ⋮ > Tags… adds or
  removes tags and creates new ones. They are stored as IMAP keywords, so
  other clients see them. New route `GET /apps/mail/api/tags` (the old UI got
  tags with the page).

- **HTML compose** (P4-1c): "Formatting" in the composer switches to a small
  rich editor (bold, italic, underline, lists, links; `RichText.tsx`). The
  message goes out as HTML with a plain-text part made from it; pasted HTML
  loses scripts, event handlers and `javascript:` links. "Plain text" switches
  back and keeps the text.

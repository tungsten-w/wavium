## Done

### Logo everywhere

- The default logo is Wavium's W drawn inline (`WaviumMark` in `@atrium/ui`),
  so it can never be a broken image. Before, the login logo was an absolute
  URL built for one host and port; a page opened through another one (a tunnel
  on another port) had no logo.
- An admin's own logo (Settings > Theming) still wins, loaded from the current
  origin.
- New places for the mark:
  - the boot screen, before the JavaScript loads;
  - the agent consent page ("Connect an agent").

  The old PHP pages (login flow, password reset, errors) already show it.

### Connectivity: leaving Google (and other providers)

- **Mail setup knows the big providers**: Gmail, iCloud, Yahoo, Outlook,
  Orange, Free, SFR and La Poste are detected from the address.
  - Servers, ports and user names are filled in and hidden; one password
    field.
  - A link to create the app password the provider wants, with one line on
    its quirks.
- **Sign in with Google** (Gmail over OAuth, Mail's own XOAUTH2 support):
  - when the admin set up a Google client, Gmail users get the button;
  - the account is created as `xoauth2`, Google's page opens, Mail checks the
    state and stores the tokens;
  - if the window was blocked or closed, the half-made account is removed.
  - New `GET /apps/mail/api/integration/google`: configured, client id,
    redirect URL.
- **Settings > Administration > Google sign-in**:
  - the steps to create the OAuth client (project, consent screen and scope,
    test users, web client);
  - the exact redirect URI with a Copy button;
  - client ID and secret, Turn off.
- **Settings > Move from Google**: one card per service, using Google's own
  exports (no API key needed):
  - **Gmail**: 2-Step Verification, then an app password, then "Add my Gmail"
    (or Sign in with Google when set up).
  - **Calendar**: subscribe to the secret iCal address (stays in sync,
    read-only), or import the exported `.ics` files into a calendar.
  - **Contacts**: import the exported `.vcf` into an address book.
  - **Drive and Photos**: Google Takeout, then Files or the desktop app.
  - Imports PUT over CalDAV/CardDAV with `If-None-Match: *`: importing twice
    skips what is already there and never overwrites. Events with their
    changed occurrences stay one object, with only the time zones they use.

### Tutorial

- **Settings > Tutorial**: nine illustrated steps:
  1. Today card;
  2. mail sorting;
  3. suggested replies;
  4. filing rules;
  5. calendar and tasks;
  6. agents;
  7. AI providers;
  8. assistant;
  9. Move from Google.

  The images are real screenshots of the demo (`core/img/tutorial/*.jpg`,
  about 640 KB), shown in a window frame on the Wavium gradient. Each step has
  a "Try it" link, Previous/Next, and the step reached is remembered.
- Dashboard: "New here? Take the two-minute tour" until the tutorial was
  opened once.

### Install

- `bash deploy/wavium/install.sh`:
  - checks Docker, Compose, memory, disk, DNS and the ports;
  - asks the domain and the admin name;
  - writes `.env` with random passwords (mode 600, never overwritten);
  - builds the image and starts everything;
  - prints the address and the admin login.
- `--update` rebuilds and restarts; `--yes` runs without questions.
- `deploy/wavium/.gitignore`: `.env`, `build.log` and `backups/` can never be
  committed.
- README: "Install it on your server" at the top.

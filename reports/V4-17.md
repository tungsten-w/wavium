# V4-17: several mail accounts and sorting that work every day

- Branch: `night/V4-17` · Instance: Claude session · Date: 2026-11-20

  tried: rule A1, see questions)

Goal from the owner: "v3/v4 100 % operational: bugs fixed, link Gmail, Orange
and other accounts, mail sorted correctly, for daily use". Everything below was
found by using the app on a fresh dev stack (Playwright, port 8093), not only
by reading code.

## Done

Accounts (`apps/mail/web/Account.tsx`, `index.tsx`, `api.ts`):

- **"Add a mail account" in the Mail sidebar.** Before, once one account
  existed, the only way to add another was typing `/apps/mail/setup` (or
  Settings > Google > "Add my Gmail"). The setup page now opens inside Mail,
  with the sidebar, "Back to mail" and the list of supported providers.
- **Username bug, any provider not in the list** (own domain, Proton Bridge,
  work server...): the IMAP and SMTP usernames stopped at the first letter
  typed (`j` for `jean@monbox.org`), so the connection failed. They now follow
  the address until the person edits them.
- **Editing an account wiped or broke it.** "New password (leave blank to
  keep)" sent an empty password, which the server tried (connection error) and
  would have saved; and a Gmail account connected with "Sign in with Google"
  was switched back to password login on any save (even a rename). Blank
  passwords are now left out and the auth method is kept.

Sorting:

- **Classification stuck 10 minutes after adding an AI**
  (`TriageService::runClassify`, `classifyOnArrival`): the run that found no
  AI paused for 10 minutes, so after adding a provider in Settings > AI the
  status still said "No AI" and nothing was sorted. "No AI" costs nothing to
  check again, so that pause no longer blocks; other pauses (budget, rate
  limit, bad key) still hold.
- **Filed mail looked lost.** A rule moved the mail on the server, but the
  Archive view (and any folder) only synced after one minute, and a single
  folder in the default "Curated" mode never synced live at all. Opening a
  list now syncs it at once, and single folders sync in Curated/category mode
  too (the label list is asked again when something moved).

Checked on the real stack and working: linking a second account (GreenMail
user) from the new button; the merged Inbox shows both accounts; the mock AI
classifies all 14 mails of both accounts; Curated hides spam/ads/newsletters
(7 of 11 shown); category chips; a rule in French ("Les mails de ... vont
dans Archive") proposed, saved, applied to the matching mail, which shows in
Archive without pressing refresh.

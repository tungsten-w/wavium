# V4-19: current Claude models for sorting, drafts and the assistant

- Branch: `night/V4-19` · Instance: Claude session · Date: 2026-11-20
- Status: done (not run against the real Anthropic API: no real key, rule A2)

The owner will sort mail with an Anthropic API key. The suggested models were
`claude-haiku-4-5` / `claude-sonnet-4-5`; the current ones are
`claude-haiku-5-5` (small: triage, $0.10 / $0.50 per M tokens, 10x cheaper
than Haiku 4.5) and `claude-sonnet-5-5` (large: summaries, drafts, assistant).
Swapping the ids alone would have broken every AI feature: current Claude
models (Opus 4.7 and later, every 5.x) answer 400 to `temperature` and to a
forced tool choice, and think by default.

## Done

- `server/ai/routing.ts`: suggestions `claude-haiku-5-5` / `claude-sonnet-5-5`.
- `server/ai/anthropic.ts`, for current models only (`currentClaude()`;
  older ids get the exact same request as before):
  - no `temperature`;
  - a forced tool (triage, rules, extract) becomes `tool_choice: auto` with
    only that tool offered and "Answer only by calling the X tool." added to
    the system prompt, at `effort: low`;
  - `max_tokens` at least 4096 so thinking cannot cut a 200–800 token answer
    (billing is on tokens used, not the ceiling; budgets do not use it).
- Thinking blocks (with their signature) are kept as `opaque` blocks
  (`AiResult.replay`, plain and streamed) and the assistant's tool loop sends
  them back first, unchanged, as current models expect. Other providers
  ignore them.

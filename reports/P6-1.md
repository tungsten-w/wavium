- Status: done

## Done

- `deploy/wavium/`:
  - `compose.yaml`:
    - `app` (Wavium image: PHP-FPM + Bun), `cron`, PostgreSQL 17.6,
      Redis 8.2, Caddy 2.10.2;
    - DB and Redis on an internal network with no internet;
    - named volumes;
    - CPU/RAM limits from `.env`;
    - health checks;
    - `ATRIUM_SERVER_URL` set for mail triage.
  - `Caddyfile`: automatic HTTPS for `WAVIUM_DOMAIN` (Let's Encrypt; local
    CA for `localhost`), HTTP→HTTPS, CalDAV/CardDAV `.well-known`, 10 GB
    uploads, 1 h timeouts, security headers.
  - `.env.example`: everything a person sets.
  - `hooks/post-installation/10-wavium.sh` (official image hook, runs once):
    - enables Mail, Calendar, Contacts, Tasks, Notes, Daily Todo, Activity
      and Dashboard;
    - cron background jobs, APCu/Redis caches, time zone;
    - mail triage on (with the AI from Settings > AI);
    - no Nextcloud sample files or example event; the admin's samples go to
      the trash bin.
  - `README.md`: build, configure, start, what runs, backups, update, a local
    try-out.
- `deploy/build.sh`:
  - works in a git worktree (`--git-path index`);
  - `WITH_DAILY_TODO=1` ships Daily Todo in the image (the old stack
    bind-mounts it).

- `deploy/wavium/backup.sh`: backup / restore / verify for this stack. It is
  the P6-3 script with the stack's services; `deploy/backup.sh` gained
  `ATRIUM_EXEC_USER`, because occ must run as `www-data` in the production
  image.

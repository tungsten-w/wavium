## Done so far

- `server/agent/reply/index.ts`:
  - `suggestReply()`: reads the thread, asks `ai.forTask(uid, 'draft')`, then
    saves a Mail draft through `phpBridge().saveDraft` (`inReplyTo` = the
    Message-ID, to = the sender, subject "Re: …"). It never sends.
  - Owner route `POST /agent/v1/reply/suggest {message_key, instruction?}`.
  - Agent tool `mail_reply_suggest` (area mail, action write). It registers
    the draft in `atrium_agent_drafts`, so `mail_send` (which needs an approval)
    and `mail_draft_update` work on it.
  - Registered in `server/agent/index.ts` as `replyModule(ai)`.

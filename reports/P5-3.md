# P5-3: Filing rules in natural language (AI proposes, human validates, applied without AI)

- Branch: `night/P5-3` (on top of `night/P5-2`) · Instance: session A · Date: 2026-11-14
- Status: done

## Done

- **Engine** `server/agent/rules/engine.ts` (pure, no AI):
  - a rule = `when` + `then`, plus a name and an account:
    - `when` (all must match): `from_domain` (subdomains too), `from`,
      `category` (mail-v2), `subject_contains`;
    - `then`: `move_to` (a folder of the same account), `mark_read`, `star`;
  - matching, first enabled rule wins (lowest id);
  - validation (at least one condition and one action, a real folder, a known
    category);
  - a readable description ("from edf.fr, category admin → move to Admin, mark
    read").
- **Module** `server/agent/rules/index.ts` (`rulesModule(ai)`, one line in
  `server/agent/index.ts`):
  - own tables:
    - `atrium_mail_rules`;
    - `atrium_mail_rule_log`: one row per mail filed, so **a mail is filed
      once**; reclassifying it or applying again does not move it again.
  - **runner** every 5 s on newly classified mail (cursor on `mail_triage`;
    history is not replayed):
    - only mail still in the inbox;
    - only the owner's rules;
    - actions through the Mail bridge: a move is a move, never a delete.
  - **AI proposal** (`ai.forTask(uid, 'rules')`): one forced tool `make_rule`.
    The folder is an enum of the account's real folders; Trash is never
    offered. The result goes through the same validation and comes back with
    a preview (matches among the last 200 inbox mails, 5 examples). **It is not
    saved.**
  - Owner routes `/agent/v1/rules`:
    - GET (rules, folders, accounts, recently filed);
    - POST (create), PATCH (enable, rename, edit), DELETE;
    - `propose`, `preview`;
    - `<id>/apply` (run once on the inbox now).
- **UI** Mail > **Rules** (sidebar, above Status):
  - write the rule in your own words → Propose → the description, how many
    mails match and examples;
  - then "Save rule", "Save and file these N now" or Cancel;
  - your rules: on/off, Apply now, delete;
  - "Recently filed".

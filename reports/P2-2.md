# P2-2: Settings > AI (providers, encrypted keys, test connection)

- Branch: `night/P2-2` · Instance: A · Date: 2026-11-13
- Status: done

## Done

- **Store** `server/ai/settings.ts` (`AiSettings`), tables `atrium_ai_providers`
  and `atrium_ai_prefs`, created by the store itself (idempotent, not in the
  agent layer's numbered migrations, so P2-3 can add its own without a clash).
  - Two scopes: **instance** (admins; every user can use it; users do not see
    its base URL) and **personal** (one user, their own key). An admin can turn
    personal providers off.
  - **Keys encrypted**: AES-256-GCM, key = HKDF-SHA256(instance secret),
    provider id as associated data (a sealed key copied to another row does not
    open). Never sent back: the page gets `hasKey` and the last 4 characters
    (only for keys of 16+ characters). If the instance secret changes, the
    provider stays listed but unusable until the key is entered again.
  - A key never follows a provider to another vendor: changing the kind needs
    the key again.
  - **Personal base URLs** go through P1-5's SSRF guard (`assertPublicWebhook`)
    when saved and before every request (a guarded `fetch`), allow list
    `ATRIUM_AI_ALLOW`. Instance providers are trusted (LAN Ollama is fine).
  - **Mock** kind offered only with `ATRIUM_AI_MOCK=1`, set in the dev
    `compose.yaml` (rule A2); mock rows are ignored elsewhere.
  - Default provider: the user's choice, else the instance default, else the
    first instance provider, else the first personal one. Disabled, deleted or
    key-less providers are skipped.
  - For features (P2-3, P2-4, P2-5): `config(uid)` (keys decrypted, server only)
    and `provider(uid, id?)` (a ready `AiProvider`, guarded when personal).
- **API** `server/agent/ai.ts`, an agent-layer module on `/agent/v1/ai/*`:
  `GET settings`, `POST providers`, `PATCH|DELETE providers/<id>`, `POST test`,
  `PUT default`, `PUT admin`. Same auth as the owner API (session, OCS-APIRequest
  header on writes, no agents). Admin = member of the `admin` group (DB lookup).
- **Page** `/settings/user/ai` ("AI providers", `core/web/shell/settings/Ai.tsx`,
  logic in `aiModel.ts`): instance list (+ add/edit/delete/enable for admins,
  instance default, personal-providers switch), personal list, add/edit dialog
  with a write-only key field ("Unchanged (Key ••••WXYZ)"), "Test connection"
  (lists models, fills a datalist for the default model, never spends tokens),
  "Test" per saved provider, default provider choice.
- Docs: `server/ai/README.md` (configured providers), `docs/lessons.md` (Bun
  SQLite placeholder order).

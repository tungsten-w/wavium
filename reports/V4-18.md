- Branch: `night/V4-18` · Instance: Claude session · Date: 2026-11-20

With several accounts and the merged Inbox, a rule only covered the account
picked in Mail > Rules (found in V4-17: an alice@ rule did not touch the same
sender in the linked account). The owner asked for "all my accounts".

## Done

- Mail > Rules: account picker "All my accounts" (the default with two or
  more accounts; a styled `Select` instead of the bare `<select>`). The
  proposal previews every inbox ("of your inboxes").
- `POST /agent/v1/rules` with `all_accounts: true`: one rule per account
  (the engine is unchanged). The target folder is matched in each account by
  role (Archive, Spam...), else by name in any case, never Trash
  (`sameFolderIn`). An account without it is skipped and named in the toast.
- "Save and file now" applies every created rule; the toast gives the total.
- Each rule in the list shows its account when there are several.

# Security policy

Please **do not** open a public issue for a security problem. Report it
privately on GitHub:
https://github.com/tungsten-w/wavium/security/advisories/new

Say what you found, how to reproduce it and what it affects. You will get an
answer within a few days.

Wavium is a fork of Nextcloud 34.0.5. A problem that also exists in Nextcloud
itself should be reported to Nextcloud too: https://nextcloud.com/security/
